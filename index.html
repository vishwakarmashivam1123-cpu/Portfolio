SkillSwap

A platform where people trade skills with each other. I built it from scratch for a friend: seven pages, secure login, and a signed Android app running on the same backend.

Add your live link: Open SkillSwap

A problem I solved

Login worked on my laptop and broke in production. There were three separate causes: a CORS origin mismatch, a Render URL suffix that sent every API call to the wrong address, and cookies blocked between the Netlify and Render domains. I fixed them with the correct allowed origins, the right API URL, and sameSite: none cookies (which also need to be secure). The same fix made login work inside the Android app.

Built with

Plain HTML, CSS and JavaScript, Node.js, Express, MongoDB Atlas, JWT cookie login. Hosted on Netlify and Render, shipped as a signed APK.
